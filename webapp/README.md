# TradingAgents 网页分析台

在浏览器里发起分析，实时看到整个过程：每位分析师调用了哪些工具、拿到的数据是否可用、多空辩论和风险讨论的每一轮发言、研究经理/交易员/组合经理的结构化决策，以及每一步的耗时和 token 用量。历史分析可以随时回放。

一次分析的页面有：

- **决策卡**：五档评级刻度，研究经理 → 交易员 → 组合经理的决策链，入场价、止损价、目标价（以及与最新收盘的距离）、仓位和程序校验结果；资料不足或校验未过时说明原因。
- **行情**：智能体分析时用的同一份固定日线快照，画成 K 线，叠加 50 / 200 日均线、成交量，以及入场、止损、目标价位线；可切换 3 个月到全部的范围，附最近 30 个交易日的数据表。
- **流程 / 辩论 / 报告** 三个标签页：流程图和每个节点的详情；多空辩论（两列）与风险讨论（三列）按轮次排开，附各自裁判的结论；全部报告按顺序排成一篇文档。

右上角可以切换涨跌颜色：默认红涨绿跌（A 股、港股习惯），也可以改成绿涨红跌。K 线另用空心阳线、实心阴线区分涨跌，不只靠颜色。

## 使用

第一次使用先构建页面（需要 Node.js 18 以上）：

```sh
cd webapp/frontend
npm install
npm run build
```

然后在项目根目录启动（或双击 `start-web.command`）：

```sh
./start-web.command
```

打开 http://localhost:8765 。接口文档在 http://localhost:8765/api/docs 。

模型服务商、密钥和数据源仍以项目的 `.env` 为准；网页上只能选择股票、日期、分析师、讨论轮数、模型名和报告语言。每次分析都会消耗模型额度。

## 开发

两个终端：

```sh
./start-web.command                       # 接口，端口 8765
cd webapp/frontend && npm run dev         # 页面，端口 5173，/api 代理到 8765
```

打开 http://127.0.0.1:5173 ，改动前端代码会即时刷新。

## 结构

| 位置 | 内容 |
|---|---|
| `tradingagents/graph/events.py` | 把一次运行变成事件流（`RunEvents`），并写入 `events.jsonl` |
| `webapp/server.py` | FastAPI 接口：发起、列出、实时流（SSE）、取消、报告 |
| `webapp/runs.py` | 一次只跑一个分析，在后台线程执行 |
| `webapp/history.py` | 从磁盘读回历史运行和报告 |
| `webapp/frontend/` | React 页面：`runState.ts` 把事件折叠成每个节点的状态，`components/` 是界面 |

每次运行的事件保存在 `<results_dir>/<代码>/<日期>/events.jsonl`，网页发起的运行报告保存在同目录的 `web_reports/<run_id>/`。

## 安全

接口没有登录，所以只在本机提供服务：启动时拒绝非本机地址，`Host` 必须是本机名，其他网站页面发来的修改请求会被拒绝（防止恶意网页偷偷发起分析消耗额度）。

仅供研究使用，不构成投资建议。
